# 普通 Chat 目录与阅读位置：会话级接入记录

2026-10-01 对 `/Applications/ChatGPT.app` 26.928.21956 做了**非官方、可撤销的渲染层接入**。入口沿用本项目的本机调试会话与 Explodex 插件；应用包、签名、对话数据库和登录状态没有修改。此实现只服务普通 Chat。Codex 的原生目录、查找和滚动仍由应用负责。

## 设计

- **识别**：只选择当前可见、处于 `ChatGPT` 模式、带有当前会话 ID 的 `.thread-scroll-container`。保留在 DOM 中但宽高为零的 Codex 历史视图不能进入 Chat adapter。以会话 ID、`data-turn-key` 和 `data-chatgpt-search-message-ids` 定位，不用标题或 DOM 顺序当持久身份。
- **目录**：挂在 Chat 正文滚动区域左侧边缘；与当前 Codex 原生组件同样在至少 4 轮时出现。每轮点击区为 36×10 CSS px，线条基准为 26×2 px，闲置时缩为约 6 px；悬停线条及相邻三轮渐次展开。预览卡片宽 320 px，显示提问及回答摘录；点击将真实提问定位到正文视口顶部约 82 CSS px。当前刻度随阅读锚点更新。只列出已渲染的轮次，辅助标签明确写“已加载的 N 次提问”。
- **阅读锚点**：按会话保存轮次 ID、消息 ID、内容块序号及内容块相对正文视口的偏移。没有正文副本或凭证。A→B→A 和渲染器刷新时优先找同一消息块，找不到时退回同一轮；若该轮也不存在，则不强行滚动到其他内容。用户滚轮、触摸或按键会取消尚未完成的恢复。
- **位置稳定**：正在阅读历史时，观察内容区域尺寸变化；只有保存的内容块相对视口确实移动才补偿。接近底部时让原生跟随继续负责滚动。插件卸载会移除目录、样式、计时器、监听和观察器。

## 已执行的验收

- 早期会话级原型曾在 2 轮对话中点击第二刻度，提问从视口外移动到距正文顶部 `81.84` CSS px；现版按 Codex 原生行为在少于 4 轮时不显示目录，当前合成回归覆盖现版点击定位。
- 真实普通 Chat：长回答中段保存内容块锚点；A→B→A 后同一块的偏移前后均为 `136.34` CSS px。渲染器刷新后存储仍在，重新打开会话时观察到另一个保存锚点的期望／实际偏移均为 `79.34` CSS px。
- 真实窗口停用：`Ctrl+C` 停止本机会话程序后，目录节点、目录样式、额度节点及插件注册均为零。
- 独立合成浏览器回归：`node scripts/e2e-chat-session.mjs` 通过 90／500／1000 轮的首轮、中段、末轮提问定位，以及 A→B→A、刷新、卸载检查；`npm test` 的 76 项测试通过。

## 原生组件对照与 2026-10-01 调整

从当前安装包的 `webview/assets/thread-user-message-navigation-rail-app-f3182b6f8d66.js`、`floating-navigation-rail-layout-c107fbd19cd1.js` 及配套 CSS 做只读核对；未修改应用包，也未将其源码复制进本项目。当前版本的 Codex 原生目录在 4 轮后出现，按钮 36×10 px、刻度 26×2 px、闲置可见约 6 px、每轮垂直间距 10 px；活动轮次提高亮度，悬停时本轮与邻近刻度伸长，右侧提示卡片宽 320 px。Chat 的本项目实现按这些可见行为重新编写。

真实窗口复核：Chat 的 5 个目录按钮中首个闲置线宽 `6.0008` CSS px，活动标记 1 个，悬停预览显示提问标题及回答摘录，卡片宽 320 CSS px；同窗口 Codex 原生目录有 57 个按钮，首个线宽 `6.0008` CSS px、按钮 36×10 px，且可见的自定义 Chat 目录为 0。原生提示卡片宽 320 px。

## 仍未完成的验收与界限

- 目录只基于宿主**已经渲染**的提问。合成 90／500／1000 轮通过，但尚未证明真实宿主中未渲染的历史轮次都可列出或先加载再跳转；不能称为“整条完整目录”。
- 真实应用完整退出／重启后的自动恢复、不同窗口和分支、生成中内容变化、图片／代码块延迟加载、浅色主题与各尺寸窗口，尚未逐一验收。合成浏览器的通过不替代这些结果。
- 已核对当前暗色主题的关键目录几何和提示卡宽度；尚未对浅色主题、缩放、完整动效曲线与复杂内容预览做逐像素对照，不能宣称所有界面与原生完全一致。Chat 预览用安全的纯文本摘录，原生 Codex 预览能渲染 Markdown、附件输出和书签；两种会话的数据结构不同，Chat 目前不展示这些原生专属内容。
- 当前的会话级程序必须保持运行。应用升级后，若 DOM 属性或布局不匹配，应停用本功能并重新核验，不应猜测节点。

## 启用与撤销

插件文件已安装在 `~/.explodex/plugins/codex-navigator`。本次会话使用 `node scripts/inject-usage-rail.mjs` 启动；以后先 `⌘Q` 完全退出应用，再从项目目录运行 `bash scripts/launch-usage-rail.sh`。该脚本同时启用 Codex 额度窄栏和普通 Chat 的目录／阅读锚点。停止 Terminal 中的程序会卸载两项 UI；完全退出应用后直接按平常方式打开，可恢复原应用状态。程序只通过本机调试会话接入，不应误称为官方 Chat 插件安装。
