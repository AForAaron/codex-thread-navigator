# 原生目录条复刻与阅读控制：实现记录

2026-09-27，当前原生静态参照版本：ChatGPT.app 26.924.22138 (11645)。

## 已实现、可运行的部分

独立预览中的目录条改为逐条 button + marker：26px 基准宽、2px 线高，默认约 6px；悬停目标和相邻三项分别展开至约 26/20/14/10px，常规 160ms 动画；支持指针浏览、点击、键盘焦点与方向键，减少动态效果时取消过渡。目录条位于对话容器左侧 16px、垂直居中，列表高度限制 min(70vh,40rem)，少于四轮时隐藏，与读取到的原生组件规则一致。

这是独立重实现，没有复制整段应用组件或执行其中代码。原生代码是结构及参数参照；没有声称已通过运行中原生窗口的像素对照。

- 长回答中根据阅读线之前最近的用户提问识别所属轮次，不再因用户气泡不可见而退回首轮。
- 阅读锚点保存消息、块序号和相对视口偏移；支持提问/回答内容恢复，旧绝对 offset 不再覆盖内容锚点。旧 v2 锚点降级到消息起点。
- ReadingViewport 区分 FOLLOWING/READING/RESTORING/JUMPING；文字 Mutation 和消息 Resize 合并到动画帧，阅读时维持内容位置；用户输入取消程序化事务；切换时 dispose 清理观察器、定时器和监听。
- 新标签页分配自己的阅读锚点命名空间；刷新保留，独立窗口不会覆盖彼此已保存的位置；新会话可从最后保存锚点回退。复制标签页的 sessionStorage 继承场景未验证，不保证隔离。
- 搜索覆盖当前完整 fixture；缓存正文索引，不在每次滚动时重新扫描全文；同一消息支持多个命中，命中包含消息 ID 和字符范围，直接定位实际文字行。使用 CSS Highlights，不重写 Markdown DOM。
- 搜索浮层可从顶部按钮打开，不要求展开宽侧栏；方向键可遍历结果。真实窗口尚未接入的来源提示始终明确。
- 快速切换使用 AbortController 和会话代次丢弃旧渲染及扫描结果。新增 500/1000 轮 fixture 用于压力回归。
