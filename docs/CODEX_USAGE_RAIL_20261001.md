## 以后如何启动

1. 完全退出桌面应用（`⌘Q`）。
2. 在 Terminal 进入本仓库根目录，运行：`bash scripts/launch-usage-rail.sh`。
3. 保持这个 Terminal 进程运行。脚本校验应用签名和本机调试端口，启动实际 `/Applications/ChatGPT.app`，加载本插件，并通过官方只读 App Server 每分钟刷新。若看见 `mounted:true, visible:true` 和三个实时值，即本次会话接入成功。

当前会话已经由 `node scripts/inject-usage-rail.mjs` 启用，无需重复启动。若关闭 Terminal 的运行进程或按 `Ctrl+C`，插件会卸载并清除 DOM／样式；完全退出应用后普通方式打开，也回到原始状态。若要移除磁盘上的本地插件文件，可删除 `~/.explodex/plugins/codex-navigator`。停用不修改对话数据或应用签名。

额度组件本身只显示 Codex 额度，不处理普通 Chat 的搜索或滚动；同一个会话启动脚本现在还会独立启用普通 Chat 的目录与阅读锚点，详见 `docs/CHAT_SESSION_RAIL_20261001.md`。调试端口只在这次以脚本启动的应用进程上开放，使用后建议完全退出应用，再按平常方式打开。
